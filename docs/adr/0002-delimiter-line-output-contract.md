# 0002 分隔行输出契约

`cmd-gen` agent 的输出契约：候选之间用独占一行的 `---CANDIDATE---` 分隔，每条候选允许是多行指令，禁止解释、markdown 围栏、编号前缀；解析器按分隔行切块，再剥围栏、去首尾空行兜底。候选是任意的多行命令时，模型手写 JSON 转义（`\n`、引号、反斜杠）的出错率远高于在行首划界，所以选分隔行而非 JSON 数组。

围栏兜底的具体做法：一个候选块里若出现成对围栏，只保留第一处开围栏到最后一处闭围栏之间的内容，围栏外的解释文字一并剥掉；不成对时退回逐行剥首尾围栏。模型违反契约、在围栏外加了解释时，解释文字不是命令，留在候选里反而喂给校验层一个必死命令，所以兜底时连同剥掉。
